## 0. 生成策略（先读这一段，能省 80% 的返工）

1. **不要一次生成整张设定板再指望它自洽**。正确做法是「**先主立绘 → 再派生**」：先生成中栏主立绘并锁定，再用它作为参考图（image reference / `--cref` / `--oref` / 即梦参考图）逐张生成三视图与细节格，最后拼版。
2. **中文书法标题与属性小字，绝大多数模型会写错**。两种解法：
   - 用能稳定渲染中文的模型（Seedream 4.0 / 即梦 / Nano Banana Pro）直接整版生成；
   - 或用 SD/Flux/MJ 生成**无文字版**设定板（提示词里加 `no text, no lettering`），文字层在 PS/Figma 里用书法字体（如「汉仪尚巍手书」「思源宋体」）+ 细线框后期排版。
3. **一致性靠「锚定句」而非长描述**：第 1 节的锚定句**逐字复制**进每一条提示词的开头，不要改写、不要精简。
4. **固定 seed + 固定参考图权重**（0.65–0.8）。三视图三张之间只改视角词，其余一字不改。
5. 服装结构用「**分层编号 L1–L9**」表达，比形容词堆叠更能锁住剪裁。

**配色纪律**：整体是**单色系（monochrome cool blue-white）**，禁止出现暖黄、暖棕、饱和粉紫。
对比只靠明度（白 ↔ 雾蓝）与材质（亚光缎 ↔ 折射水晶）拉开，不靠色相。
宝石蓝（`#3F6E96`）是全局唯一的高饱和色，**每个视图只能出现 2–3 处**，多了就俗。

## 5. 性格气质与表演要点

- **基底**：清冷、疏离、仙气——像一件不该被触碰的冰器。
- **反差**：任性、小骄纵——居高临下的慵懒里藏着少女的撒娇。
- **姿态语言**：下巴微抬 5°，眼睑下垂半睁（傲慢的困倦），肩颈线绷直，动作幅度小而精准。
- **允许的表情**：不屑一瞥／冷淡垂眸／得意浅笑（不露齿）／ momentary 好奇／委屈抿唇。
- **禁止**：大笑、露齿、夸张惊讶、Q 版化、卖萌比心。
- **氛围道具**：随行霜粒、脚下冰晶碎裂、身侧若隐若现的冰鸾虚影。

## 8. 画风与渲染规格

- **风格坐标**：东方幻想仙侠 × 高级定制时装插画 × 游戏角色设定集（不是日系 anime，也不是欧美写实人像）。
- **渲染**：2.5D 半写实 CG，亚光瓷肌 + 水晶折射 + 硬纱透光；类似国产二次元大厂角色立绘的质感。
- **光影**：左上前侧主光（冷白 6500K，柔边），右后补冷蓝轮廓光勾出纱边；浅景深（f/2.0 感），背景轻微虚化。
- **质感三重点**：① 皮肤**亚光、无油光**；② 纱料**半透、边缘发光**；③ 水晶**有折射与内部裂纹**。
- **细节密度**：8K 级，刺绣可数针、羽丝可数根；但**面部保持干净**，不做过度纹理。
- **禁止**：塑料感、硬边投影、暖色调、过饱和、油腻高光、五颜六色的宝石。

## 13. 参数建议与验收清单

**参数**
| 工具 | 建议 |
|---|---|
| Midjourney v7 | `--ar 2:3 --style raw --s 200-260 --q 2`；一致性用 `--oref <主立绘URL> --ow 700` |

**验收清单（逐条打勾）**
- [ ] 五处绝对一致：**发色渐变分界位置 / 头冠羽片数量与朝向 / 胸前菱形蓝晶位置 / 裙摆前短后长比例 / 后跟羽翼**
- [ ] 三视图等高、同一头身比、同一鞋跟高度
- [ ] 全局只有一个高饱和色（宝石蓝），且总出现次数 ≤ 3
- [ ] 画面没有暖黄／暖棕，白色不是死白而是带蓝的冷白
- [ ] 手指数量正确、关节自然；耳尖是「微尖」不是精灵长耳
- [ ] 面部干净，没有过度纹理与浓妆
- [ ] 背景亮度比人物低 15–20%，人物轮廓清晰
- [ ] 文字层（若有）无乱码；中文书法标题为竖排、有留白
